# Game of Guessing Numbers

## A project with a random generated secret number.
This is a project assignment that assigns a secret number and allows the user a number of attempts based on difficulty level picked.

## Features
* Allow the computer to generate a random secret number within the given range
* Allow user to pick difficulty levels with assigned attempts.
* Count attempts and print remaining guesses
* End game on correct guess or when attempts run out.

## Requirements
* Python: use the built-in random module

## How to Run
1. Clone the Project
```bash
git clone https://github.com/abigailnkimani-cyber/week2_assignment.git
```
2. Run the app
``` python guess_numbers.py
```
